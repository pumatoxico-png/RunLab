# RunLab
Meu primeiro projeto em python para analisar corridas
## Funcionalidades
-Calcular ritmo médio.
-Calcular velocidade média.
-Validar distância e tempo.
-Classificar o ritmo e a dificuldade da corrida
## Tecnologias
-Python 3
## Como executar
1. instale o Python 3.
2. Baixe arquivo runlab.py
3. Execute o programa
4. Informe a distância e o tempo da corrida
